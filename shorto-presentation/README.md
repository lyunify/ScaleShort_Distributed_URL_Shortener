
# Shorto Project Presentation

This standalone site explains Shorto's architecture, storage, and collision handling. The working URL shortener is served separately by the backend at http://localhost:8080.

**Prerequisites:** Node.js


1. Install dependencies:
   `npm ci`
2. Run the app:
   `npm run dev`

Open http://localhost:3000. See [the macOS setup guide](../MACOS_SETUP.md) to run the backend and Redis.
